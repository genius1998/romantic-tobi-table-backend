# 토미 캐릭터 성장 가이드

## 캐릭터 기본 정보

- 캐릭터 이름: **토미 (Tommy)**
- 최대 레벨: **5레벨**
- 성장 방식: 포인트를 소비하여 토미에게 먹이를 주면 EXP(경험치)가 증가하고 레벨업

---

## 레벨업 조건 (EXP 기준)

| 현재 레벨 | 레벨업 필요 EXP | 비고 |
|---|---|---|
| 레벨 1 → 2 | 300 EXP | |
| 레벨 2 → 3 | 600 EXP | |
| 레벨 3 → 4 | 900 EXP | |
| 레벨 4 → 5 | 1,200 EXP | |
| 레벨 5 | 최대 레벨 (1,500 EXP 한도) | 더 이상 레벨업 없음 |

- EXP는 소비한 **포인트와 1:1**로 증가합니다 (1포인트 먹이 = 1 EXP).
- 레벨업 후 남은 EXP는 다음 레벨로 이월됩니다.

---

## 먹이 주기 방법

1. 메인 화면에서 토미를 선택합니다.
2. "먹이 주기" 버튼을 누릅니다.
3. 소비할 포인트 양을 입력합니다.
4. 포인트가 차감되고 토미의 EXP가 증가합니다.

---

## 현재 상태 확인

- 현재 포인트: 메인 화면 상단에 표시
- 현재 레벨: 토미 캐릭터 옆에 표시
- 현재 EXP / 다음 레벨까지 필요 EXP: 프로필 화면에서 확인

### 다음 레벨까지 필요 EXP 계산 예시

레벨 2이고 현재 EXP가 250이라면:
- 다음 레벨(3) 까지 필요 EXP: 600
- 남은 EXP: 600 - 250 = **350 EXP 필요**
- 즉, 350포인트 이상을 먹이로 소비해야 레벨 3이 됩니다.

---

## 의상 시스템

포인트로 토미의 의상을 구매하고 장착할 수 있습니다.

| 카테고리 | 설명 |
|---|---|
| HEAD | 모자, 리본 등 머리 장식 |
| EYE | 선글라스 등 눈 장식 |
| FACE | 수염 등 얼굴 장식 |

- 한 번 구매한 의상은 영구 소유입니다.
- 장착(equip) / 해제(unequip) 가능합니다.

---

## 업적과 성장의 관계

| 업적 | 조건 | 연동 |
|---|---|---|
| FEEDING | 먹이 주기 누적 횟수 | 먹이 줄 때마다 업적 진행도 증가 |
| ATTENDANCE_SEQ | 연속 출석 | 매일 인사할 때마다 진행도 증가 |
| RECEIPT | 영수증 등록 횟수 | 영수증 인증 성공 시 진행도 증가 |
