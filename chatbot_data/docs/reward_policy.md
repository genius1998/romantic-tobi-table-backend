# 포인트 및 리워드 정책

## 포인트 적립 유형 (PointTransactionType)

| 타입 | 설명 | 적립량 |
|---|---|---|
| `RECEIPT_EARN` | 영수증 인증 시 적립 | 결제금액 ÷ 100 |
| `GREETING_REWARD` | 매일 인사하기 | 10포인트 |
| `ACHIEVEMENT_REWARD` | 업적 달성 보상 | 업적별 차등 |
| `ADJUST` | 관리자 수동 조정 | 임의 |

## 포인트 사용 유형

| 타입 | 설명 | 소비량 |
|---|---|---|
| `FEED_SPEND` | 토미에게 먹이 주기 | 사용자 입력량 |
| `CLOTHES_BUY` | 의상 구매 | 의상별 가격 (기본 100~500포인트) |
| `REWARD_REDEEM` | 기프티콘 교환 | 리워드별 cost_point |
| `LEVELUP_SPEND` | 레벨업 소비 | TODO: 정책 확정 필요 |

## 리워드 (기프티콘) 교환

### 업적 기반 기프티콘

| 조건 | 리워드명 | 금액 |
|---|---|---|
| 연속 출석 업적 전체 완료 | `ATTENDANCE_5000` | 5,000원 |
| 먹이 주기 업적 전체 완료 | `FEEDING_5000` | 5,000원 |
| 영수증 등록 업적 전체 완료 | `RECEIPT_5000` | 5,000원 |
| 전체 업적 완료 | `ALL_ACHIEVEMENTS_10000` | 10,000원 |

- 각 업적 보상은 **1회만** 수령 가능합니다.
- 기프티콘에는 고유 코드가 발급됩니다.

### 포인트 직접 교환 리워드 (예시 데이터)

| 리워드명 | 필요 포인트 | 설명 |
|---|---|---|
| 커피 쿠폰 | 1,000포인트 | 아메리카노 교환권 |
| 영화 예매권 | 5,000포인트 | 영화 1인 예매권 |
| 치킨 기프티콘 | 8,000포인트 | 교환처에서 사용 가능 |
