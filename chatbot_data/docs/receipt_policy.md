# 영수증 인증 정책

## 인증 가능 조건

1. **구미시 소상공인 가게** 영수증이어야 합니다.
   - 소상공인 DB에 등록된 가게만 인증됩니다.
   - 대형 프랜차이즈나 대기업 체인점은 인증되지 않을 수 있습니다.
2. 영수증에 **가게명, 결제금액, 결제일자**가 포함되어야 합니다.

---

## OCR 인식 과정

1. 이미지 업로드 → Google Vision API로 텍스트 추출
2. GPT 기반 파서로 가게명/금액/날짜/주소 구조화
3. 벡터 유사도 + 텍스트 유사도로 DB 내 가게 매칭
4. 매칭 성공 시 포인트 자동 적립

### 매칭 방식 (내부 기준)
- **RULE_SCORE**: 가게명 유사도 + 주소 유사도가 기준 이상
- **RULE_NAME_ONLY**: 가게명이 거의 완벽 일치하고 유일한 경우 (주소 없어도 가능)
- **LLM_REVIEW**: 규칙으로 결정 어려울 때 AI가 최종 판단
- 모두 실패 시: 인증 거절

---

## 인증 실패 사유

| 코드 | 설명 | 해결 방법 |
|---|---|---|
| `receipt_store_name_missing` | OCR에서 가게명을 인식하지 못함 | 가게명이 잘 보이도록 다시 촬영 |
| `no_candidate` | DB에서 유사한 가게를 찾지 못함 | 해당 가게가 소상공인 DB에 없을 수 있음 |
| `low_confidence` | 후보 가게가 있으나 매칭 신뢰도 낮음 | 주소가 포함된 영수증으로 재시도 |
| `소상공인 가게가 아닙니다` | 매칭된 가게가 없음 | 구미시 소상공인 가맹점에서 사용한 영수증인지 확인 |
| `이미 인증된 영수증입니다` | 동일 가게+날짜+금액 조합이 이미 등록됨 | 같은 영수증은 중복 제출 불가 |

---

## 중복 영수증 정책

- 동일한 가게명 + 결제일자 + 결제금액이 동일한 영수증은 **중복으로 처리**됩니다.
- 중복 영수증은 포인트가 적립되지 않습니다.
- 중복 체크 활성화 여부: 서버 설정(`receipt.duplicate-check.enabled`)으로 관리됩니다.

---

## 포인트 적립 공식

```
적립 포인트 = 결제금액 ÷ 100 (소수점 버림)
```

예시:
- 3,200원 → 32포인트
- 12,500원 → 125포인트
- 900원 → 9포인트

---

## 자주 발생하는 OCR 오류 패턴

- `메가엠지씨커피` → `메가커피`로 정규화 처리됨
- `금오공과대학교`, `금오공대` → `공대`로 정규화
- `(주)`, `㈜`, `주식회사` 등 법인명 접두사 자동 제거
- 도로명 주소의 층/호 표기 오류 자동 교정 (예: `1f` → `1층`)
